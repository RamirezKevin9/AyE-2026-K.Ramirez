Evaluacion Unidad I


1)Un obrero necesita calcular su salario semanal, el cual se obtiene de la siguiente
manera: Si trabaja 40 horas o menos se le paga un salario de $16 por hora, si trabaja
más de 40 horas se le paga un salario de $16 por cada una de las primeras 40 horas y
un salario de $20 por cada hora extra. Hacer una funcion que devuelva el salario semanal del obrero, esta misma debe de recibir como parámetro la cantidad de horas trabajadas. (3 puntos)

2)Hacer una funcion que le pida al usuario que ingrese numeros hasta que se ingrese 0, cuando el usuario ingrese 0 se devuelve la suma de todos los numeros que ingresó. La funcion no recibe parametros. (2 puntos)

3)Hacer una funcion que pida al usuario ingresar una palabra, se debe recorrer esa palabra y si encuentra cualquier vocal contarla, devolver la cantidad de vocales. La funcion no recibe parametros. (2 puntos)

4)Hacer una funcion que le pida al usuario una palabra, si la palabra es un palindromo devolver la palabra, si no lo es volver a pedir la palabra hasta que lo sea. La funcion no recibe parametros. (3 puntos)


Se debe de manejar las excepciones correspondientes solamente en la entrada de datos del usuario.
